# Affiliate Revenue Intelligence Platform

A production-style Analytics Engineering project for analyzing affiliate traffic,
conversions, revenue, commission, and profitability.

## Objective

Build a reliable analytics platform that transforms raw affiliate data into
tested, documented, and business-ready datasets.

## Business Questions

- Which affiliates generate the most revenue and profit?
- Which campaigns have high traffic but low conversion?
- Which merchants generate the highest commission margin?
- Which products receive high traffic but have poor conversion?
- Which traffic sources perform best?
- How are revenue, conversion rate, and commission changing over time?

## Technology Stack

- Python
- SQL
- Snowflake
- dbt
- Git / GitHub
- Airflow
- Power BI
- AI / LLM analytics

## Architecture

Raw Data
→ Snowflake
→ dbt Staging
→ dbt Intermediate
→ dbt Marts
→ BI / Analytics
→ AI Analytics
